Configure OpenCode

Create the config file that connects OpenCode to Nemotron 3 Ultra via NVIDIA's API.

Windows (PowerShell)
macOS / Linux
# Create config directory New-Item -ItemType Directory -Force "$env:USERPROFILE\.config\opencode" | Out-Null # Write config (uses env var, never stores key in file) @' { "$schema": "https://opencode.ai/config.json", "model": "nvidia/nvidia/nemotron-3-ultra-550b-a55b", "provider": { "nvidia": { "npm": "@ai-sdk/openai-compatible", "name": "NVIDIA", "options": { "baseURL": "https://integrate.api.nvidia.com/v1", "apiKey": "{env:NVIDIA_API_KEY}" }, "models": { "nvidia/nemotron-3-ultra-550b-a55b": { "name": "Nemotron 3 Ultra" } } } } } '@ | Set-Content -Encoding utf8 "$env:USERPROFILE\.config\opencode\opencode.json" # Set API key persistently setx NVIDIA_API_KEY "nvapi-YOUR-KEY-HERE" # Close and reopen PowerShell, then: $env:NVIDIA_API_KEY = "nvapi-YOUR-KEY-HERE"
# Create config directory mkdir -p ~/.config/opencode # Write config cat > ~/.config/opencode/opencode.json << 'EOF' { "$schema": "https://opencode.ai/config.json", "model": "nvidia/nvidia/nemotron-3-ultra-550b-a55b", "provider": { "nvidia": { "npm": "@ai-sdk/openai-compatible", "name": "NVIDIA", "options": { "baseURL": "https://integrate.api.nvidia.com/v1", "apiKey": "{env:NVIDIA_API_KEY}" }, "models": { "nvidia/nemotron-3-ultra-550b-a55b": { "name": "Nemotron 3 Ultra" } } } } } EOF # Set API key (add to ~/.bashrc or ~/.zshrc for persistence) export NVIDIA_API_KEY="nvapi-YOUR-KEY-HERE"

Official Limitations (Free API Tier)

Key constraints from NVIDIA's model card for nvidia/nemotron-3-ultra-550b-a55b:

Free Tier Limits

  • Rate limits: Not published. Expect ~10-20 req/min, ~50k-100k tokens/min
  • Daily quota: Not published. Resets on 429 errors
  • No SLA: Free tier can be throttled or disabled anytime
  • Logging: NVIDIA logs usage for security/product improvement
  • Context: Up to 1M tokens (API may enforce lower)
  • Concurrent: Limited (single-digit typically)

Model Capabilities

  • 550B total / 55B active (LatentMoE: Mamba-2 + MoE + Attention)
  • 1M token context (requires chunked prefill)
  • 12 languages: EN, FR, ES, IT, DE, JA, KO, HI, PT, ZH
  • Reasoning: Configurable via enable_thinking: true/false
  • Benchmarks: SWE-Bench 69.7% (NVFP4), GPQA 87.9%, RULER 1M 94.0%

Production at Scale (Millions of Users)

  • Free tier not suitable for high-volume production
  • Self-host: 4× B200 (~$12-16/hr cloud) or 8× H100 (~$24-32/hr)
  • Implement: token-bucket rate limiter, exponential backoff, semantic cache
  • Fallback: OpenRouter nvidia/nemotron-3-ultra-550b-a55b:free
  • Set reasoning_budget: 512-1024 for cost/latency control
